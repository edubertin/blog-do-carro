# Segurança

Não publique tokens, credenciais, dados pessoais, payloads de pagamento ou arquivos `.env` em issues ou pull requests.

Quando o repositório estiver no GitHub, vulnerabilidades devem ser relatadas de forma privada pelo recurso **Security Advisories** do próprio repositório. Inclua impacto, versão afetada e passos mínimos de reprodução, sem dados reais de usuários.

O checkout atual é demonstrativo e não processa pagamentos. Qualquer indício de cobrança, persistência de pedido ou exposição de dados deve ser tratado como falha crítica.
